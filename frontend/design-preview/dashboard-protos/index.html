工作台重设计 ·
把荧光黄换掉，让判断更值钱。

现状是纯黑底 + 荧光黄大标题，与全站「纸白 + 绯红」的语言不兼容：黑块过重，黄字刺眼，而且真正重要的信息（谁该跟进、还差多少钱）被埋在大字后面。这 10 款原型全部保留品牌绯红作为唯一信号色，改用中性纸底承载密度。

保留绯红 #be123c 只用于「需要你立刻处理」的信号；其余全部中性；中文优先、数字等宽。
去掉荧光黄 #f2ff00、纯黑大面积铺底、48px 以上的口号式标题占位。
补上今日判断（依据/动作/影响）、跟进队列、漏斗卡点、风险信号、汇率敞口、竞标、团队。

怎么选

#方案最适合信息密度关键取舍
01晨报编辑版每天开工前读一遍中极简但有阅读门槛，卡片为零
02指挥台业务 + 主管通用高深色信号卡很抢眼，需控制只用一块
03Bento 卡片移动端 / 年轻团队中高渐变主卡好看，但需克制只用一张
04时间轴台账个人执行，按天推进中强依赖日程数据质量
05商机看板销售自己管单中弱化「今天」概念，偏商机
06数据仪表主管周会 / 复盘高弱化待办，偏结果
07AI 副驾新人 / 需要引导中依赖 AI 质量，文本量大
08墨金夜间版长时间盯盘 / 夜班高暗色与全站纸白不一致，需整站同款
09双栏聚焦周目标管理中高目标与动作分离，今天信息略少
10瑞士网格数据量大的成熟团队很高硬朗、缺温度，适合 B 端老手

推荐组合：以 02 指挥台 为骨架（信息最全、扩展性最好），把 01 的「判断三段式（依据 / 动作 / 影响）」搬进深色信号卡；如果团队偏年轻、移动端多，改用 03 Bento。夜班场景再单独提供 08 暗色皮肤。
