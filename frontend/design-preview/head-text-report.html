页面「右上方文字」体检评分与精致化

对象＝每个界面右上角的那组文字：页面标题行右侧的统计块（标签＋数字＋小字）、状态说明、以及全局顶栏右侧的账号信息。 共巡检 52 个界面，逐项量了「计算字号 / 字重 / 颜色 / 字距」，给出评分并统一改版。

结论一句话体检结果

字号档位（改前）14 档9 / 10 / 10.5 / 11 / 11.5 / 12 / 16 / 17 / 18 / 19 / 20 / 22 / 23 / 24px
字重档位（改前）6 档400 / 500 / 600 / 700 / 800 / 900
灰色套数（改前）5 套绿灰 / 蓝灰 / 暖棕 / 纯黑 / 主题灰
改后3 档11px 标签 · 20px 数值 · 11px 说明

「土」的根因有三个：①数字大小各写各的（同一个「统计数字」角色在 14 个界面里有 9 种字号）； ②颜色不跟主题——晨白主题是冷调靛蓝，但右上文字大量用绿灰 #6a7975、暖棕 #9b937f， 甚至 rgba(0,0,0,.6) 纯黑；③两处整块跑偏——产品维护／发货跟踪压着暖米黄径向底＋琥珀色数字， 开发信回流页用荧光黄 #c8f23c。三者叠一起就是「土」。
